# 项目简介:
本 Demo 实现了 USB 3.2 的数据回环与带宽测试功能，以及 DFU固件下载功能。
默认下载地址为 0x000000，该地址可通过修改prj\src\rtl\usb3_2_user_layer\spi_flash_controller-FLASH_OFFSET 进行修改。

# Project Overview:
This demo implements USB 3.2 data loopback and bandwidth testing, as well as DFU (Device Firmware Upgrade) functionality.
The default download address is 0x000000; this can be modified by changing the `FLASH_OFFSET` parameter in `prj\src\rtl\usb3_2_user_layer\spi_flash_controller`.
